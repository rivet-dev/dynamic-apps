---
title: Filesystem
description: Each VM presents a normal POSIX filesystem to guest code, backed by a virtual filesystem inside the kernel and isolated from the host disk.
---

Each VM presents a normal POSIX filesystem to guest code: the standard `node:fs` and `node:fs/promises` APIs work as usual, backed by a virtual filesystem that lives inside the kernel and never touches the host disk.

```ts
import { NodeRuntime } from "secure-exec";

const rt = await NodeRuntime.create();
await rt.exec(`
  import { mkdirSync, writeFileSync, readFileSync } from "node:fs";
  mkdirSync("/workspace", { recursive: true });
  writeFileSync("/workspace/hello.txt", "hello from the sandbox");
  console.log(readFileSync("/workspace/hello.txt", "utf8"));
`);
await rt.dispose();
```

Secure Exec uses the same virtual filesystem model as agentOS. For the full reference (seeding files, host read/write, mounts, and storage backends), see the [agentOS filesystem documentation](https://agentos-sdk.dev/docs/filesystem).
