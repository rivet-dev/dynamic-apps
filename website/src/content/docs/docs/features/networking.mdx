---
title: Networking
description: Network access for sandboxed code.
---

Guest `fetch()`, `node:http`, and raw sockets all flow through the kernel socket table, so guest code never touches the real host network. The `network` permission on the VM config gates what the guest may reach.

```ts
import { NodeRuntime } from "secure-exec";

// Allow outbound networking, or scope it with a rule set.
const rt = await NodeRuntime.create({
	permissions: {
		network: { default: "deny", rules: [{ mode: "allow", patterns: ["api.example.com"] }] },
	},
});
```

Secure Exec uses the same networking model as agentOS. See the [full reference](https://agentos-sdk.dev/docs/networking).
