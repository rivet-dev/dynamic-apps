---
title: Filesystem Mounts
description: Project real host directories and remote storage into the VM's virtual filesystem.
---

Filesystem mounts project an external directory (a real host directory, Amazon S3, Google Drive, or a remote sandbox-agent) into the VM's virtual filesystem so guest code reads and writes it as an ordinary POSIX directory.

Declare host directory mounts on the VM config:

```ts
const rt = await NodeRuntime.create({
  mounts: [
    { guestPath: "/mnt/host-data", hostPath: "/abs/path/on/host", readOnly: true },
  ],
});
```

Secure Exec uses the same mounting model as agentOS. For the full reference (host directories, S3, Google Drive, overlays, and read-only/writable semantics), see [Sandbox Mounting](https://agentos-sdk.dev/docs/sandbox).
