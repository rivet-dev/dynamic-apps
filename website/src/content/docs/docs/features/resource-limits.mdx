---
title: Resource Limits
description: Cap per-VM memory, CPU time, file descriptors, processes, and sockets so guest code can never exhaust the host.
---

Secure Exec bounds each VM with per-VM caps on memory/heap, CPU time, file descriptors, processes, and sockets, so runaway guest code can never exhaust the host.

Set limits on the VM config you pass when creating a runtime:

```ts
import { NodeRuntime } from "secure-exec";

const rt = await NodeRuntime.create({
	limits: {
		v8HeapLimitMb: 256, // cap guest JS heap
		maxProcesses: 64, // cap concurrent processes
		maxFileDescriptors: 256, // cap open fds
	},
});
```

Secure Exec uses the same resource-limits model as agentOS. See the full reference at [agentos-sdk.dev/docs/resource-limits](https://agentos-sdk.dev/docs/resource-limits).
