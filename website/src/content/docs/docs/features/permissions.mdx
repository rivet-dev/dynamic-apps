---
title: Permissions
description: Control what sandboxed code can access on the host.
---
import { LinkCard } from '@astrojs/starlight/components';

Permissions are a per-scope policy (`fs`, `network`, `childProcess`, `process`, `env`, `tool`) checked against every guest syscall, so denied operations are rejected with `EACCES` before any host resource is touched.

```ts
import { NodeRuntime } from "secure-exec";

const rt = await NodeRuntime.create({
  permissions: { fs: "allow", network: "deny" },
});
```

Secure Exec uses the same permissions model as agentOS. See the agentOS reference for all scopes, rule sets, and the complete model.
