# Project references

- Use https://rivet.dev/llms.txt as the canonical documentation index for future RivetKit work.
- App-defined RivetKit actors are a required Dynamic Apps capability. Preserve
  and verify actor deployment, state, actions, events, callbacks, and direct
  HTTP serving end to end whenever the serving runtime changes.
- After merging changes to `docs/` or `examples/` into `main`, publish them to rivet.dev by following `SYNCING_PRODUCT_DOCS.md` in a checkout of `rivet-dev/website`.
