### What we'll build

- A `/generate` route that turns a user's prompt into an app's files and deploys them.
- A build and repair loop that sends build errors back to the model before anything goes live.
- One Dynamic App per user project, served from your own server at its own path.
- App Actors that give each project its own backend state and SQLite database.

### Similar tools

This is the same job as Vercel for Platforms with the v0 Platform API, Cloudflare Workers for Platforms, Freestyle, or Netlify. On Rivet the apps run inside your own server through a router you control, and each one comes with durable Actors instead of a separate database to set up.

### Open questions

- `appsRouter` serves each app under a path such as `/apps/:appId/`. Custom domains and wildcard subdomains per app are unverified.
- Dynamic Apps is in preview, and its API may change before general availability.
