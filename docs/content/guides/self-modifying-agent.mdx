### What we'll build

- An agent with a tool that writes code for new tools and publishes it to the agent's own Dynamic App.
- A build and repair loop that sends build errors back to the model until the release compiles.
- App Actors that hold each tool's data, so it is still there after the next release.
- A tool list that the agent refreshes from its app before each turn, so new tools show up on the next turn.

### Similar tools

This is the same job as Cloudflare Dynamic Workers with Code Mode, Letta self-editing agents, or a Voyager-style skill library. On Rivet the generated tools run as a deployed app with their own durable Actors, so a tool can keep data between calls and across new versions of its code.

### Open questions

- Dynamic Apps is in preview, and its API may change.
- A failed build never replaces the active release. Rolling back to an earlier release that built but misbehaves is unverified.
- Actor state carries across releases only if the generated code migrates its own schema. Confirm how migrations run when a release changes the schema.
